Install Case Compass

Version 3.0 · iPhone, iPad, Android, Mac, Windows, and Chromebook

Why an address is needed. Case Compass encrypts your records inside your browser. Browsers allow encryption, private storage, and offline use only on a secure (HTTPS) address or on your own computer at http://localhost. Opening index.html directly from a folder will show an explanation instead of the app.

1. Put the app on an HTTPS address (one time)

Case Compass is a set of static files. It has no server, accounts, or database to set up, and it never sends your records anywhere. Any static HTTPS host works. The simplest free option is GitHub Pages:

  1. In the GitHub repository, open Settings › Pages.
  2. Under Build and deployment, choose Deploy from a branch, select the main branch and the / (root) folder, then Save.
  3. After a minute or two, GitHub shows the address, for example https://YOUR-USERNAME.github.io/Case-Compass/.

The app's code is public on a public repository, but your records are not: they are created and encrypted on your own device and are never uploaded to GitHub or anywhere else.

2. iPhone or iPad

  1. Open the HTTPS address in Safari.
  2. Tap the Share button, then Add to Home Screen, then Add.
  3. Open Case Compass from the Home Screen icon and create your vault there.
Important on iPhone and iPad.
  • The Home Screen app and a Safari tab keep separate storage. Create and use your vault in the Home Screen app.
  • When a site is used only in a Safari tab, Safari may delete its stored data after about seven days without a visit. Home Screen apps are not subject to that limit. This is another reason to install to the Home Screen and to keep encrypted backups.
  • Deleting the Home Screen icon deletes the vault stored inside it. Make a backup first.

Saving files on iPhone: when you create a report or backup, choose Share… and then Save to Files to keep it in the Files app (iCloud Drive or On My iPhone), or choose Download and find it in Files › Downloads.

3. Android

  1. Open the HTTPS address in Chrome.
  2. Tap the ⋮ menu, then Install app (or Add to Home screen).
  3. Open Case Compass from the new icon and create your vault.

4. Computer (Mac, Windows, Chromebook)

Hosted address: open it in Chrome, Edge, Safari, or Firefox. In Chrome or Edge you can choose the install icon in the address bar to get a separate app window.

Run it locally instead: if Python is installed, open a terminal in the Case Compass folder and run:

python3 -m http.server 8080

then visit http://localhost:8080. Keep the terminal open while you use it. Your vault belongs to that browser and that address; use the same address each time.

5. First use

  1. Create a passphrase of at least 12 characters (four or more random words work well). Write it down and keep it somewhere safe. It cannot be recovered.
  2. Read the short orientation on the Home screen.
  3. Make your first encrypted backup in Reports › Backup & Restore and store it somewhere other than this device.

6. Updates and offline use

After the first visit, the app's files are stored on the device so it opens and works without an internet connection. Links to outside websites still need the internet. When you are online, Case Compass checks for a newer version and offers Update now; you can also use Reports › Settings › Check for app update.

7. Moving to a new device

Case Compass does not sync between devices. To move: make an encrypted backup on the old device, copy the .ccbackup file to the new device, open Case Compass there, and choose Restore from an encrypted backup on the welcome screen.

8. Troubleshooting

  • “Open Case Compass from a web address” – the file was opened directly. Use the HTTPS address or http://localhost.
  • “Secure storage is not available” or “Storage is blocked” – usually private browsing or a privacy setting that blocks site data. Use a normal window. Case Compass never falls back to storing records without encryption.
  • “Storage is full” – make a backup, then remove large evidence files you no longer need, or allow more storage in the browser.
  • Forgot passphrase – it cannot be recovered. If you have a backup and remember its passphrase, erase the vault from the lock screen and restore the backup.
