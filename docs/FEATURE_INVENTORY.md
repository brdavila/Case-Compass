# Feature inventory and gap analysis – Case Compass 3.0

Prepared November 13, 2026.

## 1. Source materials: what could and could not be reviewed

The build specification asked for version 3.0 to be a consolidation of the existing project's files (four earlier HTML planners, a Resource Atlas of about 77 entries in nine categories, a resource organizer spreadsheet, preparedness packets, security checklists, court packets, a monthly example, and two protocol manuals – 24 files in total).

**None of those files were present** in this repository (it contained only a README) or in any other repository available to the build session. They were therefore **not reviewed**, and nothing in this release claims to have preserved their exact wording, data structures, or entries. The gap is stated in the app (Resources › Guides & Downloads › About the original project files), in this document, and in the validation report.

What was done instead:

| Original material (described generically) | How 3.0 covers its purpose | Status |
|---|---|---|
| Four earlier planner HTML apps | Rebuilt from the specification: all record types, timeline, reports, encryption. A tolerant import adapter reads earlier planner JSON exports/backups (and CSV), preserving original IDs, dates, and every original field. | Rebuilt; exact legacy format unverified |
| Court Resource Atlas (~77 entries, 9 categories) and Resource Organizer / worksheet spreadsheets | New 101-entry directory in nine sections compiled from official sources and providers' own sites on 2026-11-13; every link checked. Parenting-class providers taken directly from the Colorado Judicial Branch directory (all 24, with 17 listed for Pueblo County), which includes every provider named in the specification. In-app CSV import lets the original atlas be added once exported from the spreadsheet. | Replaced with verified data; original entries not migrated |
| Preparedness packets, start-here and first-steps guides, "why these protections matter" | Native guides: Start Here (interactive checklist), Why These Protections Matter, Using Case Compass on a Possibly Monitored Device. | Rebuilt |
| Mobile security checklist, digital and home safety guides, home security checklist, scenario protocol manual, modular protocols v2 | Protection & Security Center: protocols A–G, 59 steps, each with what/why/how/cautions/resources, completion date, notes, and linked evidence. | Rebuilt |
| Family court packets, 50/50 parenting checklist | Court Forms directory (67 official forms, 12 groups, applicability notes) and the Parenting-Time Preparation Checklist. | Rebuilt |
| Planner user guide | User Manual (PDF, 18 pages with screenshots), Quick Start (2 pages), documentation guide in the app. | Rebuilt |
| Monthly example report (DOCX and XLSX) | Fictional sample package in `samples/` generated by the app's own report engine (monthly report in PDF/DOCX/HTML, 12-sheet workbook, attorney packet, evidence index, parenting record, checklists, blank forms, CSV). | Rebuilt as clearly labeled fictional samples |

**To complete the original consolidation later:** add the original files to the repository; then (1) compare the atlas entries against `data/resources-data.js` and add any verified entries that are missing, marking dead ones `retired`; (2) export one real backup from the earlier planner and run it through Reports › Import to confirm the field mapping; (3) bundle any handouts worth keeping as downloads under `docs/` and list them in `data/guides-data.js` (`LIBRARY`).

## 3. Removed or intentionally excluded

- Divorce and common-law marriage workflows (per the specification).
- Remote accounts, cloud sync, analytics, third-party scripts, and AI processing.
- Automatic legal-deadline calculation.
- Background push notifications (cannot be delivered reliably by a private offline web app without a server).
